# Layout_youtube_com_grid

A front-end practice project focused on recreating the core user interface of a YouTube video
page. This project demonstrates the use of modern CSS layout techniques like Flexbox and
Grid to build a responsive and organized media dashboard.

[Page link](https://carlab09.github.io/layout_youtube_com_grid/)

## Technologies used:
*  HTML
*  CSS
*  Dummy Data: Utilizes Lorem Ipsum text and placeholder images for rapid prototyping.


## Features
* Featured Video Section: Large hero-style layout for the primary video content including title, view count, and description.
* Sidebar Recommendations: A vertical list of related videos with thumbnails and metadata (Author, Views, and Date).
* Typography & Hierarchy: Focused on matching YouTube's font weights and spacing for a familiar user experience.

## Current Implementation Details
#### The layout uses a two-column grid system:
* Main Content (Left): Occupies the majority of the screen width to prioritize the video player.
* Sidebar (Right): A fixed-width column designed to hold a scrollable list of video cards.
